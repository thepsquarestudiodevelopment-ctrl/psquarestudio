Step 3: Check Browser Console

Open your browser's Developer Tools and check the Console tab:

  • Press F12 or Ctrl+Shift+I (Windows) / Cmd+Option+I (Mac)
  • Go to the Console tab
  • Refresh the page and look for lightbox initialization messages

Step 4: Common Issues & Fixes

  • Images not showing: Check that image paths like assets/img/portfolio/Graphic Design/1.jpg exist on your server
  • Paths relative to wrong location: Ensure paths are relative to your HTML file location
  • CORS errors: If images are from external sources, they need proper CORS headers
  • Lazy loading delay: Images might not load immediately, wait a moment before clicking
